# Emsc2010-A3
My individual project for EMSC2010

This repository contains -->
- uncleaned dataset
- cleaned dataset
- colab code
- 500 word reflection
- A3 Poster

To run the code download the cleaned dataset: 
open the colab ipynb, 
save a new copy in drive, 
connect to runtime, 
upload your cleaned dataset file, 
press run all.

-- if Error message: Using nbformat v5.10.4 and nbconvert v7.17.1 shows, just download raw file.
